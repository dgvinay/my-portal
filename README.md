# my-portal
Portfolio website

My portfolio on the web. Created using Angular, Bootstrap, and FontAwesome.

#### Note on jQuery
- This project avoids using jQuery for Angular component logic.
- Use Angular templates, services, and native DOM APIs instead of jQuery-based DOM manipulation.
